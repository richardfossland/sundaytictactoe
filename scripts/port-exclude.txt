# scripts/port-exclude.txt
#
# Paths that scripts/port-from-chess.sh strips out of a cherry-picked
# sundaychess commit before committing it here, and that
# scripts/port-status.sh ignores when it decides whether a chess commit is
# "infra" (portable) or "chess-only" (nothing to port).
#
# One glob per line. `*` matches anything, including `/` (so `lib/chess/**`
# and `lib/chess/*` behave the same — there is no directory-boundary
# distinction). `[` and `]` are treated as LITERAL characters, not a bracket
# expression, because Next.js dynamic-route folders such as `[tournamentId]`
# are real directory names on disk. Blank lines and `#` comments are ignored.
# See scripts/lib/port-common.sh for the matcher.
#
# Rationale, by group:
#
# Chess rules/engine/coach/puzzles — TTT has its own game logic (lib/ttt/**)
# and none of this applies.
