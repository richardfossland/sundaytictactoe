# scripts/port-ignore.txt
#
# Manual allowlist for scripts/port-status.sh: chess commits that would
# otherwise show up as backlog but shouldn't, because TTT already carries
# an equivalent change that predates every automatic recognition method
# (cherry-pick trailer, "Port of sundaychess#NN", chess-side "Port: TTT
# #NN") — either it was part of TTT from the initial clone (2026-06-16), or
# it was ported by hand before either porting convention existed. Each SHA
# below was verified by diffing the chess commit's file list against the
# corresponding TTT commit before being added here — do the same before
# adding more; don't add an entry just because a commit "looks routine".
#
# Two entry shapes, one per non-comment, non-blank line:
#
#   <chess-sha-or-#NN>   free-text comment
#     A single chess commit. Either its full/abbreviated SHA (on chess/main)
#     or `#NN`, its sundaychess PR number — NN is resolved to the squash
#     commit the same way port-status.sh resolves a "Port of
#     sundaychess#NN" reference. Comment is everything after the first
#     run of whitespace; it isn't parsed, so it may itself contain "#".
#
#   pattern:<ERE>
#     Skip every chess commit whose *subject* matches this bash-flavoured
#     extended regex (tested with `[[ "$subject" =~ $pattern ]]`). No
#     trailing comment on a pattern line — put an explanation on the line
#     above instead. Whole-class escape hatch: use this for a class of
#     commit that never needs a real port, not for one-off equivalents
#     (those get an explicit entry above so they stay individually
#     auditable).
#
# A line starting "# " (or bare "#") is a full-line comment; "#NN" (hash
# directly followed by a digit, no space) is a PR-number entry instead —
# both begin with the same character, so the space is what tells them
# apart. Blank lines are ignored.
